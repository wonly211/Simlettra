## 这是什么版本

这是澄笺首个较完整的开发版本，用于验证单 Worker 自有域名邮箱的产品闭环、数据模型和运维路径。当前已经没有明确缺失的首发产品功能，但仍有真实 Cloudflare Free、外部服务、浏览器、安全和真人验收缺口。

当前版本适合继续开发和使用隔离测试资源验收，不适合直接接管生产邮箱，也不应对外称为首发完成。

## 已包含能力

### 部署与账号

- 单 Cloudflare Worker 同时承载网页、HTTP、收信、Queue 和每小时定时任务入口；
- `D1 + R2` 默认部署，以及独立的 `D1 + KV` 部署配置；
- 三步网页初始化建立唯一管理员、首个邮件域名和管理员主邮箱；
- 主邮箱密码登录、可撤销会话、改密、管理员重置、`init_key` 恢复和唯一管理员转让；
- 管理员创建、禁用和恢复普通用户，用户注销七天恢复及期满清理。
- 管理员生成、反复查看和撤销一次性账号邀请码，受邀人使用绑定域名填写邮箱前缀并创建正式账号。

### 地址与组织

- 多邮件域名、每用户一个主地址、个人别名和全局地址策略；
- 新用户默认 20 个个人别名额度、5 个组织创建额度；
- 地址占用、别名保留期、默认发件地址、显示名称、置顶和排序；
- 每个组织一个共享地址和一名创建者管理员，支持邀请现有用户、三种邀请偏好、成员发信开关、退出、继承、删除和七天恢复。

### 邮件闭环

- Email Routing 收信、R2/KV 对象完整性、Queue 解析、防重和原子可见提交；
- 个人及组织统一收件箱、安全 HTML、远程图片控制、附件下载和常见图片预览；
- 已读、星标、归档、垃圾邮件、垃圾箱、批量整理和永久删除；
- 中文正文与组合搜索、标准邮件关系会话归并；
- 服务端草稿、自动保存、富文本或纯文本、附件、冲突副本；
- 站内直投，以及通过 Resend 或 SMTP2GO 的站外投递、逐收件人状态、默认及备用路线、回调、防重和配额；
- 回复、回复全部、转发，以及组织地址保留与移除时的共享可见性规则。
- 早期逻辑配额表兼容升级，以及自发自收邮件在会话详情中的物理邮件去重。

### 外部连接与数据维护

- ntfy、Gotify、WxPusher、Telegram 和 Bark 通知网关；
- 经过验证的个人外部邮箱自动转发；
- Cloudflare 免费资源快照、保守停止、用户和组织逻辑存储配额、域名月度发件配额；
- 用户或组织邮件导出、管理员本地加密完整备份、空白资源恢复；
- 旧系统只读迁移、数量对账、重复执行和失败报告；
- 收信暂停、基础拒收规则、全域收信、未分配来信查看与认领；
- 网页新邮件自动更新，以及收信、发信、存储和定时维护健康摘要。

## 配置变化

全新部署需要：

1. 自动创建或复用一个名称以 `-meta` 结尾的 D1；
2. 自动创建或复用一个名称以 `-raw` 结尾的 R2 存储桶或 KV 命名空间；
3. 自动创建或复用一个名称以 `-tasks` 结尾的 Queue；
4. 每小时 Cron；
5. 静态网页资源；
6. `INIT_KEY`；
7. 独立的 `CONFIG_KEY`；
8. 每个收信域名的 Cloudflare Email Routing；
9. 需要站外发信时配置 Resend 或 SMTP2GO；
10. 需要外部通知时配置相应通道。

正式发布默认在 Cloudflare 创建 Worker 页面连接 GitHub，保持 `pnpm run build` 与 `npx wrangler deploy` 默认命令，构建变量只填写 `SIMLETTRA_STORAGE_MODE`。D1、R2/KV 和 Queue 按实际 Worker 项目名称自动创建或复用；`INIT_KEY` 与 `CONFIG_KEY` 由唯一管理员在 Worker 运行时配置中以可查看文本变量管理，不进入 GitHub 或构建变量。本地 CLI 验收仍可使用 `wrangler.jsonc` 或 `wrangler.kv.jsonc`，两份模板的占位编号不能直接用于真实部署。

## 数据影响

- D1 结构由 25 个只增不改的正式迁移建立；
- D1 保存账号、权限、邮件关系、状态、任务和对象登记等权威事实；
- 邮件原始 MIME、正文、附件、草稿对象、导出和备份分卷保存在当前 KV 或 R2；
- 搜索索引和部分衍生关系可由权威数据重建；
- D1 与 KV/R2 不具备整次跨资源原子事务，依靠完整性门槛、幂等任务、检查点、对账和空白资源恢复处理失败；
- 从 `0023` 升级到 `0025` 的行为、配置、数据、检查和回退见[0025 升级说明](0025升级说明.md)。

## 当前质量证据

- 全量自动化：56 个测试文件、234 项测试通过；
- Vue 模板可访问性自检覆盖 1,723 个元素和 338 个原生交互控件，当前收件箱的 39 个可见控件没有空名称；
- 本地 `D1 + KV` 与 `D1 + R2` 完整备份恢复自检通过；
- KV/R2 旧系统迁移重复执行和六类失败场景通过；
- 从 `0023` 到 `0025` 的本地升级、25 个迁移、115 张既有表行数、配额和内部投递新结构及独立回退目标通过；两种早期逻辑配额形状专用自检通过；
- R2 与 KV 最终部署产物均通过 Wrangler `4.120.1` 部署预检；
- R2 与 KV 产物均通过绑定、存储模式、Queue、Cron 和网页回退静态检查；严格部署会拒绝全零资源编号，生成配置不再保留本机绝对路径；
- Cloudflare 连接 GitHub 部署配置的 R2/KV 本地自检通过；生成配置保留控制台运行变量但不携带 `INIT_KEY`、`CONFIG_KEY` 或第三方凭据；
- 本地性能工具应用全部 25 个迁移，在 50 名用户、100,000 封邮件和 10 个读取线程下连续两次通过；较保守的列表第 95 百分位为 258.41 ms，详情为 3.22 ms；
- 本地安全集合包含 8 个测试文件、52 项回归和生产密钥扫描，并覆盖真实邀请码的失败响应、审计字段与控制台输出脱敏，以及多地址收信和 Queue 失败重投。
- 2026-08-14 的 npm 官方公告审计确认 38 个生产及可选依赖为零已知风险；完整锁文件有一项仅位于 Drizzle 开发工具链的中等 `esbuild` 开发服务器风险，生产产物不包含该旧版本，限制与发布前重查见[生产依赖安全审查记录](../验收/生产依赖安全审查记录.md)。

2026-08-13 已在隔离的真实 Cloudflare 资源完成 R2 模式的 D1、R2、Queue、Cron、网页、双密钥和 Worker 部署，生产 D1 已迁移到 `0025`，线上初始化鉴权与桌面及手机向导检查通过。2026-08-14 已把运行绑定统一为管理员可查看的 `INIT_KEY`、`CONFIG_KEY` 文本变量，删除旧变量和全部 Secret，并再次通过未初始化状态与 `init_key` 鉴权复核。该实例仍未提交初始化数据，也没有接入 Email Routing；其余证据仍不能代替 Provider、完整浏览器矩阵或真人验收。

## 已知限制和缺口

### 本地产品能力

- 需求 `3.02` 的账号邀请码规则和纵向切片已经完成；管理员管理、一次性注册、权限、限速、失败回滚、日志脱敏和桌面及手机浏览器流程均有本地证据。真实 Cloudflare D1 并发、部署日志总审计与跨浏览器复核仍列为发布门槛。

### 真实环境缺口

- R2 模式已经完成隔离资源创建、远程迁移、部署和密钥，但尚未完成网页初始化与首次收信；KV 模式仍未真实部署，两种模式的升级、备份、恢复和回退仍未完成；
- 接近 20 MB 邮件尚未通过真实 Workers Free Email Routing 与 Queue consumer 验证；
- Resend、SMTP2GO 的真实单封限制、投递、回调、乱序和故障切换尚未验收；
- 五种通知通道、真实外部邮箱转发、资源指标、Queue、Cron 和期满清理尚未完成远程联调；
- 真实旧系统数据副本迁移尚未演练。

### 浏览器、性能和安全缺口

- Chrome、Edge、Firefox、Safari 的完整关键流程尚未全部执行；
- 回复、手机站内发送、会话、永久删除、全域认领、个人与组织导出，以及可见页面自动更新均已补做桌面或 `390 × 844` 手机验收；自动更新的原生后台、离线、登录与登出生命周期仍待真实浏览器补验；
- 本地性能结果不包含真实 Worker 调度、网络、KV/R2 正文读取和浏览器渲染；
- 发布前仍需完成跨浏览器恶意样本、真实部署日志总审计、外部故障注入和人工安全签署；
- 尚未由非程序员在全新环境中完成从部署到多人共享收发的完整流程。

### 当前实现边界

- 健康状态根据 D1 权威账本推断，不主动探测 Provider 或通知通道是否在线；
- 自动更新在页面可见且在线时每 60 秒重载当前列表，不是实时推送；
- 中文正文搜索至少输入两个汉字；
- 未分配来信认领的当前本地保护线为单次 30 封，尚不是最终产品上限；
- 完整恢复只写入迁移版本一致的全新空白资源，不覆盖已有 D1、KV 或 R2；
- 当前没有产品内一键升级、一键回退或一键迁移；
- 选择 R2 或 KV 后不能在已初始化系统中直接切换存储方式。

## 首发不包含

- 原生手机应用；
- 日历、网盘、收费托管、营销群发和企业审批；
- 浏览器新邮件通知；
- 动态验证码二次验证和端到端加密；
- 最近收件人、定时发送、撤回、已读回执和邮件模板；
- 组织多管理员、任务分派、内部批注、值班轮换和多级部门；
- Cloudflare Email Sending；首发域外发信只支持 Resend 和 SMTP2GO。
