# 澄笺 | Simlettra 第一批工程骨架

## 文档状态

- 阶段：正式工程骨架
- 状态：已完成
- 建立日期：2026-08-11
- 依据：需求基线-0001、ADR `0001`、`0005`、`0012`、`0029` 和当前 `AGENTS.md`

## 本批目标

建立一个可以本地启动、类型检查、自动测试和生产构建的单 Worker 工程，并用最小系统状态切片证明 Vue 网页、Hono HTTP 接口和 Worker 入口能够共同工作。

## 本批范围

1. 使用一个根级 `package.json` 和统一 pnpm 命令。
2. 建立 `src/worker`、`src/web`、`src/modules`、`src/shared`、`migrations`、`tests` 和 `tools` 边界。
3. 同一个 Worker 导出 `fetch`、`email`、`queue` 和 `scheduled` 四种入口。
4. Vue 网页通过 `/api/system/status` 读取系统状态。
5. Hono 只处理 HTTP 路由、响应和安全响应头，系统状态由应用服务提供。
6. 建立 ESLint、Prettier、TypeScript、Vitest Workers pool 和 Vite 构建检查。
7. 生产迁移目录只建立规则，不把六批数据模型草案未经 D1 审查直接转成正式迁移。

## 明确不在本批实现

1. Cloudflare D1、KV、R2、Queue 和 Email Routing 的真实资源绑定。
2. 初始化管理员、配置首个域名、密码登录和会话。
3. 收信、邮件解析、邮箱列表、写信、通知、备份和迁移业务。
4. 把验证性原型搬入生产源码。

## 依赖选择

| 依赖 | 用途 | 维护与许可判断 | 当前取舍 |
| --- | --- | --- | --- |
| Vue 3、Vite、官方 Vue 插件 | 网页与构建 | 活跃维护，MIT | 已由 ADR `0005` 接受 |
| Cloudflare 官方 Vite 插件、Wrangler | Worker 本地开发、构建、类型和部署 | Cloudflare 官方维护，MIT 或 Apache-2.0 | 与单 Worker 部署直接对应 |
| Hono | HTTP 路由和中间件 | 活跃维护，MIT | 只放在 HTTP 边界，不进入业务核心 |
| Vitest Workers pool | Worker 边界集成测试 | Cloudflare 官方维护，MIT | 测试真实 Worker 导出，而不是只测普通 Node 函数 |
| TypeScript 6 | 生产代码和契约类型 | 当前仍受 typescript-eslint 正式支持，Apache-2.0 | 暂不使用尚未被当前 lint 工具链支持的 TypeScript 7 |
| ESLint、typescript-eslint、eslint-plugin-vue、Prettier | 代码规则和格式 | 活跃维护，MIT | 建立统一检查，避免不同入口逐渐失去一致性 |

以上依赖均不进入 Cloudflare 计费资源模型；除 Vue 和 Hono 外，其余依赖只用于本地开发、检查和构建。

## 验收条件

1. `pnpm check` 完整通过。
2. 生产构建只生成一个 Worker 部署单元和对应网页资源。
3. Worker 集成测试能够通过 `/api/system/status` 取得未初始化状态。
4. 未知 API 返回稳定的简体中文错误结构。
5. `email` 在系统未初始化时明确拒收，Queue 消息不被静默确认。
6. `README.md` 与 `AGENTS.md` 写明统一命令和当前阶段。

## 验证结果

2026-08-11 已完成以下验证：

1. `pnpm install` 成功，锁文件已生成；pnpm 只允许 `esbuild` 和 `workerd` 执行安装期构建脚本。
2. `wrangler types` 成功生成当前 Worker 环境与运行时类型。
3. Prettier、ESLint、Vue、Worker、配置和测试的严格 TypeScript 检查全部通过。
4. 2 个测试文件中的 3 项测试全部通过，覆盖系统状态应用服务、正式 Worker HTTP 入口和未知 API 错误结构。
5. Vite 生产构建成功，只生成一个 `simlettra` Worker 部署单元和一组客户端静态资源。Worker 入口为 56.54 kB，gzip 后 15.19 kB；客户端主脚本为 62.81 kB，gzip 后 25.01 kB。
6. 使用浏览器验证 `1440 × 900` 桌面视口和 `390 × 844` 手机视口；页面标题、简体中文正文、系统状态和版本均正确，手机没有横向溢出，浏览器控制台没有警告或错误。
7. 本批未连接真实 Cloudflare 资源，也未执行远程部署；这些内容不属于本批完成声明。
