# 第三十八批账号邀请码注册

## 状态

本地需求、架构、迁移、实现、自动化、升级回退和桌面及手机浏览器闭环已经完成；真实 Cloudflare Free 与跨浏览器验收尚未执行。

## 目标

在继续默认关闭自由注册的前提下，让唯一系统管理员生成并自行转交账号邀请码，受邀人使用绑定域名创建主邮箱和正式账号。

## 需求依据

- 需求 `3.02`：新用户由管理员创建或通过邀请码注册。
- 需求 `9.09`、`9.13`：记录重要权限变化，但不记录密钥；注册等高成本操作具有频率限制。
- [需求变更 0010](../需求/变更记录/0010-确定账号邀请码注册规则.md)。
- [0046 以可重复展示的加密一次性邀请码完成账号注册](../架构决策记录/0046-以可重复展示的加密一次性邀请码完成账号注册.md)。

## 验收条件

1. 只有唯一系统管理员可以生成、反复查看和撤销邀请码；普通用户返回 `403`。
2. 单个已启用域名自动绑定，多个域名时管理员必须选择；注册页面只显示绑定域名并让受邀人填写邮箱前缀。
3. 邀请码没有时间期限，注册成功后不可再次使用，撤销后立即失效。
4. 邀请码摘要与加密副本进入 D1，明文不进入网址、日志和审计；管理员列表仍能显示完整值。
5. 注册原子建立用户、正式密码、主地址、默认个人别名与组织额度、默认发件偏好、会话、使用记录和审计。
6. 地址冲突、并发重复使用或审计失败不留下部分账号，也不错误消耗邀请码。
7. 错误验证按来源限速，公开接口执行同源检查。
8. 桌面和 `390 × 844` 手机视口完成管理员管理和受邀注册，无横向溢出或控制台错误。

## 实现结果

1. 正式迁移 `0023-账号邀请码注册.sql` 新增邀请码、一次性使用记录和注册限速三张表，以及一次性消费和域名删除触发器。
2. `src/modules/registration-invitations/` 实现随机码、摘要、AES-GCM 加密、来源 HMAC、管理员管理、公开验证和原子注册。
3. 管理员接口提供列表、生成和撤销；公开接口提供邀请码验证和正式注册，邀请码始终在 JSON 请求正文中传递，不进入 URL。
4. Vue 设置页新增“账号邀请码”，支持单域名自动选择、多域名选择、复制、状态、注册账号与撤销；登录页新增两步受邀注册。
5. 新注册用户直接使用本人设置的正式密码，并获得当前登录会话；默认个人别名额度为 20、组织创建额度为 5。
6. 本地升级回退工具已经改为以 `0022` 为来源、`0023` 为目标，并保证断言失败时也关闭临时数据库，不再用清理错误掩盖真实失败。

## 非目标

1. 不代发邀请邮件，不生成包含邀请码的链接。
2. 不支持批量邀请码、指定受邀邮箱、使用次数大于一次或独立有效期。
3. 不改变管理员直接创建带临时密码用户的既有能力。
