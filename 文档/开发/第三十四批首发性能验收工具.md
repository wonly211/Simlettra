# 第三十四批：首发性能验收工具

## 状态

- 状态：已完成
- 完成日期：2026-08-13
- 工程变化：新增本地性能工具、命令和验收记录；无产品运行代码、依赖或 D1 迁移变化

## 完成内容

1. 新增 `tools/本地性能验收.mjs`，自动应用当前全部正式迁移并建立 50 名用户和 100,000 封合成邮件。
2. 使用 10 个 Node.js 读取线程同时打开同一临时数据库，各执行 20 次列表与 20 次详情查询，共采集每类 200 个样本。
3. 列表基准保留当前邮箱服务的授权、完整性、状态、会话与发件人关联结构；详情基准保留当前详情授权查询结构。
4. 工具核对用户、邮件、完整性、邮件头和邮箱条目数量，并在执行查询前检查全部外键。
5. 新增 `pnpm test:performance` 并纳入 `pnpm check`，以后正式迁移或邮箱查询变化会重复执行规模基准。

## 验证结果

- 第一次：列表第 95 百分位 296.91 ms，详情 3.04 ms；最大值分别为 349.05 ms 和 5.80 ms。
- 第二次：列表第 95 百分位 111.52 ms，详情 0.98 ms；最大值分别为 117.40 ms 和 1.97 ms。
- 两次都低于 2,000 ms 本地数据层阈值，临时数据在结束后自动清理。
- 工具通过 Node.js 语法检查、ESLint 和 Prettier。

## 结论边界

本批证明当前正式 D1 结构和常用邮箱查询在本机合成规模下有充足余量，但不证明真实页面已经在两秒内可操作。完整结果仍取决于 Worker、真实 D1、KV/R2、网络和浏览器，验收-26保持“部分通过”。
