# 第二十一批免费资源用量与保守停止

## 状态

已完成。

## 目标

让唯一系统管理员看到当前 D1 与实际采用的 KV 或 R2 免费资源用量、产品总容量、剩余额度、统计范围、数据来源和最后更新时间；在预计新增存储会越过产品停止值时，阻止新增写入，但继续允许登录、阅读、导出、备份和永久删除。

## 已确认边界

- Cloudflare 当前免费额度就是 Simlettra 的产品总容量，不显示或使用付费扩展空间。
- 官方账号级指标、Simlettra 本地估算、过期数据和不可用状态必须清楚区分。
- 管理员可以设置更低的预警与停止比例，但不能超过免费额度。
- 任何增加存储的操作先建立容量预留；成功后转为待快照对账，明确失败或超时后释放。
- 官方指标不可用时使用本地登记估算，并保留更大的安全余量；不能宣称账号一定不会产生费用。
- Cloudflare 只读 API Token 由管理员管理，使用配置加密主密钥加密保存到 D1，普通日志和审计不保存明文。

## 实现口径

- 默认预警比例为 `80%`，默认停止比例为 `95%`。
- 使用 Cloudflare 精确账号级指标时按管理员停止比例准入；只使用本地估算时，实际停止值最多为免费额度的 `80%`，为同账号其他项目和指标缺口保留空间。
- D1 官方值来自数据库详情与账号数据库列表的 `file_size`；本地估算使用 D1 查询结果的 `size_after`。
- KV 官方值来自 GraphQL `kvStorageAdaptiveGroups`；R2 官方值来自 `r2StorageAdaptiveGroups`。本地对象存储估算使用 `object_registry` 当前未删除对象的登记字节数。
- 手动刷新立即保存不可改写快照；每小时定时任务在已配置凭据时刷新。

## 正式数据结构审查

正式迁移 `0015-免费资源用量与容量预留.sql` 建立四张表：

1. Cloudflare 资源只读配置。
2. D1、KV、R2 预警与停止阈值版本。
3. 不可改写的平台资源用量快照。
4. 增加存储前的平台容量预留。

## 验收条件

- 只有系统管理员可以查看和修改 Cloudflare 资源配置、阈值与快照。
- 管理员可以保存、查看、替换和删除只读 API Token，并手动刷新资源用量。
- D1 与当前 KV/R2 都显示已用、总量、剩余、来源、范围和更新时间。
- 官方接口成功、权限不足、临时失败和未配置 Token 均形成可观察且不误导的状态。
- 快照不可改写，阈值按版本替换，配置和阈值修改写入安全审计。
- 收信、草稿附件和已发送副本在增加对象前取得 D1 与当前对象存储的容量预留；预计越过停止值时拒绝新增。
- 失败释放预留，成功进入待对账；新快照能够消化已经包含在指标中的旧预留。
- 桌面和 `390 × 844` 手机浏览器无横向溢出，控制台无错误。

## 非目标

- 本切片不实现用户和组织逻辑存储配额。
- 本切片不展示 Workers 请求、D1 行读写、KV 操作次数、R2 A/B 类操作次数或 Queue 操作额度。
- 本切片不承诺未经真实 Cloudflare Free 账号验证的指标延迟和权限组合已经上线可用。

## 验证结果

- 正式迁移已在全新本地 D1 应用成功，完整迁移账本当前包含 79 张业务表。
- 高保真自动化覆盖迁移、管理员权限、配置加密、快照来源、阈值版本、容量预留、收信、草稿附件和已发送副本，共 42 个测试文件、174 项测试全部通过。
- Prettier、ESLint、Cloudflare 类型生成、网页、Worker 与测试 TypeScript 检查以及安全单 Worker 生产构建全部通过；构建产物不包含 `.dev.vars` 或已知密钥内容。
- 桌面与 `390 × 844` 手机浏览器均能清楚显示账号总量和当前资源双口径；阈值表单可以保存并显示结果，长资源编号和 Token 输入不会造成横向溢出，控制台没有警告或错误。
- 当前本地环境未配置 Cloudflare 只读 Token，因此页面准确显示“仅 Simlettra 本地估算”；真实 Cloudflare Free 账号接口、权限组合、指标延迟和共享账号扣减仍需远程验证。
