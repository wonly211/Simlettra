# 第二十四批管理员本地备份与完整恢复

## 状态

本地纵向切片已完成，进入真实 Cloudflare Free 远程恢复演练前的后续开发阶段。

## 目标

让唯一系统管理员生成包含权威 D1 数据和当前 KV/R2 对象的可验证备份，把备份安全保存到本地，并能在空白 Cloudflare 资源中完成有证据的完整恢复。

## 已实现行为

1. 管理员网页可以创建系统备份、查看运行状态，并下载清单和每个原始分卷。
2. 在线备份按 D1 表分页和对象逐项推进，使用现有后台任务账本；Queue 消息发送失败时可以由 Cron 补投。
3. 清单记录迁移版本、存储模式、表数量、对象数量、总字节、配置密钥版本要求，以及每个分卷的行数、大小和 SHA-256。
4. 本地工具可以校验清单哈希、分卷完整性、表行数、对象登记引用和二进制字段，并生成 D1 导入、对象上传、搜索重建和检查计划。
5. `pack` 默认把原始分卷封装为 AES-256-GCM 加密本地容器；`unpack` 会在输出任何明文前验证元数据认证和每个分卷的认证标签、大小与摘要。
6. `apply` 只接受空白 D1，要求迁移版本与清单一致，并按正式迁移的外键拓扑导入权威数据。可空自引用采用先置空后回填，不可处理的循环直接拒绝。
7. KV 或 R2 对象上传后逐项回读，核对实际大小和 SHA-256；对象失败不会被清单或 D1 记录掩盖。
8. 搜索数据不从备份导入。恢复会为完整邮件建立搜索重建状态和后台任务，搜索未完成时明确报告 `search_rebuild_pending`。
9. `finalize` 重新执行六项检查，全部通过后才把恢复运行标记为成功。
10. D1 保存恢复运行、六个阶段检查点和六项检查结果，但不记录邮件正文、附件内容、备份密码或配置密钥。

## 重要边界

1. 网页下载的是可校验原始分卷，不是已经加密的本地备份；管理员应使用 `pack` 生成默认加密容器后再长期保存。
2. 首发不支持覆盖现有系统。恢复目标必须是空白 D1 和对应的空白 KV/R2 资源。
3. D1 外部 SQL 不支持把整次导入包在显式事务中；跨 D1、对象和搜索也不存在原子提交。任一步失败后必须废弃目标资源，从空白目标重新恢复。
4. 备份不包含 `init_key` 或配置加密主密钥。清单只记录恢复所需的配置密钥版本，管理员必须在目标部署配置中另行准备。
5. 当前实现提供默认加密容器；第六批数据模型允许的“明确警告后二次确认保存未加密本地备份”尚未提供独立命令，不得写成已经支持。

## 本地工具命令

```powershell
node tools/本地备份恢复.mjs validate --manifest 清单.json --parts 分卷 --manifest-sha256 清单摘要
node tools/本地备份恢复.mjs plan --manifest 清单.json --parts 分卷 --manifest-sha256 清单摘要 --output 恢复计划
node tools/本地备份恢复.mjs pack --manifest 清单.json --parts 分卷 --output 加密备份
node tools/本地备份恢复.mjs unpack --container 加密备份 --output 解密目录
node tools/本地备份恢复.mjs apply --manifest 清单.json --parts 分卷 --manifest-sha256 清单摘要 --output 恢复计划 --config wrangler.jsonc --database DB --storage-mode r2 --bucket simlettra-mail --confirm-empty-target RESTORE_EMPTY_TARGET
node tools/本地备份恢复.mjs finalize --manifest 清单.json --parts 分卷 --manifest-sha256 清单摘要 --output 恢复计划 --config wrangler.jsonc --database DB --storage-mode r2 --bucket simlettra-mail --restore-run-id 恢复运行编号
```

备份密码只通过 `SIMLETTRA_BACKUP_PASSWORD` 或 `--password-file` 提供。KV 模式把 `--storage-mode r2 --bucket ...` 替换为 `--storage-mode kv --binding MAIL_OBJECTS_KV`。远程资源需要显式增加 `--remote`。

## 当前验证

1. 本地自检覆盖多页表合并、二进制摘要、清单哈希拒绝、严格数据插入、加密与解密、错误密码拒绝、外键拓扑、自引用回填和不可空循环拒绝。
2. 临时本地 `D1 + KV` 与 `D1 + R2` 已完成从迁移、空白检查、D1 导入、对象上传回读、搜索待完成、`finalize` 到恢复成功的闭环。
3. 备份接口测试 `2/2` 通过，导出与资源相关测试 `13/13` 通过。
4. Wrangler 在当前受限环境不能写入用户日志目录，会输出 `EPERM` 告警，但命令结果和测试退出码正常。
5. 真实 Cloudflare Free 的远程 D1、KV、R2、大备份耗时、操作额度、限速和中断恢复仍需单独演练。
