# 界面设计授权记录

## 授权信息

- 授权日期：2026-08-14
- 授权人：项目所有者
- 授权范围：Simlettra 整个网页界面的信息层级、布局、视觉、交互、响应式和可访问性设计
- 当前状态：生效

## 授权内容

项目所有者明确说明自己不参与 UI 专业判断，并授权设计负责人独立完成整个界面设计。设计过程不再逐批请求项目所有者确认，项目所有者以最终获得设计精良、可实际使用的界面为目标。

设计负责人可以直接决定：

- 页面信息层级、导航结构和视觉重点。
- 桌面、平板和手机的布局变化。
- 色彩、字体、间距、控件、图标和状态表现。
- 日常邮件、写信、设置、管理、登录和初始化页面的交互呈现。
- 为改善可用性和可访问性而进行的非业务性界面调整。

## 授权边界

本授权不允许设计工作自行改变：

- 已确认的产品能力、权限和数据可见范围。
- 收信、发信、删除、恢复、迁移、备份和配额等业务规则。
- 安全确认、危险操作影响说明和服务端授权检查。
- 已接受架构决策中的部署、存储、认证和公共契约。

如果界面设计必然需要改变以上内容，仍需由项目所有者决定。

## 决策记录方式

- 第一批和第二批界面设计由项目所有者显式确认。
- 自本授权生效后，后续纯 UI 决策由设计负责人依据本授权直接标记为“已决定”。
- 实现完成不等于设计合格，必须经过桌面、手机、键盘、可访问性和浏览器视觉验收。
