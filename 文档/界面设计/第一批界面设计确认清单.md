# 第一批界面设计确认清单

## 确认信息

- 批次状态：已确认
- 确认日期：2026-08-14
- 确认方式：用户回复“第一批 UI 设计全部按推荐”
- 影响范围：登录后的桌面与手机网页界面

## 确认结果

| 编号  | 要确定的事情 | 已确认结论                                                             | 状态   |
| ----- | ------------ | ---------------------------------------------------------------------- | ------ |
| UI-01 | 整体风格     | 采用“澄明工作台”：现代、安静、清晰，略有书信气质                       | 已确认 |
| UI-02 | 桌面总体布局 | 采用全高三栏：约 224 px 邮箱导航、400 至 440 px 邮件列表、自适应阅读区 | 已确认 |
| UI-03 | 手机总体布局 | 采用单栏分层，邮箱导航放入抽屉，不压缩桌面三栏                         | 已确认 |
| UI-04 | 手机主要入口 | 手机底部提供邮件、写信、设置三个主要入口                               | 已确认 |
| UI-05 | 邮件会话     | 会话按时间纵向展开或收起，不使用横向卡片时间线                         | 已确认 |
| UI-06 | 写信承载方式 | 桌面在阅读区内展开，手机使用独立全屏页面                               | 已确认 |
| UI-07 | 设置结构     | 设置分为个人、协作、系统管理，每项功能进入独立页面                     | 已确认 |
| UI-08 | 设计顺序     | 先设计收件箱、阅读、写信、设置四个核心界面，再扩展其他页面             | 已确认 |

## 影响说明

- 当前邮件、组织、设置和管理员能力不删除，只重新组织入口、层级和视觉权重。
- 第一批确认的是整体方向，不表示现有前端已经完成改造。
- 具体邮件列表、阅读操作、搜索、附件和状态表现由第二批继续确认。
- 写信细节、设置分组细节和手机交互细节由后续批次继续确认。
