## 资源与迁移

1. 发现账号中已有同类 D1 和 R2 资源，因其来源和内容不能确认而没有复用或覆盖。
2. 新建独立生产 D1、R2 和 Queue，使用独立的生产 Worker 名称。
3. `wrangler d1 migrations apply` 的远程命令字符串通道在触发器迁移处返回 `incomplete input`；同一个未经修改的迁移文件通过 D1 文件导入通道成功。
4. 根据 [ADR 0048](../架构决策记录/0048-远程迁移使用D1文件导入并沿用Wrangler账本.md) 建立 `tools/远程正式迁移.mjs`，继续使用唯一 `d1_migrations` 账本。
5. 在空白临时远程 D1 中从 `0001` 顺序应用到 `0025`，第二次执行没有重复应用；外键检查返回零行。
6. 故意失败的远程文件导入没有留下探针表，也没有留下伪造迁移账本记录。
7. 临时验证 D1 已删除；生产 D1 已完整应用 25 个正式迁移，最新账本为 `0025`，外键检查返回零行。

## Worker 与密钥

1. 生产构建通过真实资源编号严格检查，产物不含本地密钥文件、已知密钥内容或本机绝对路径。
2. Worker 已绑定生产 D1、R2、Queue、每小时 Cron 和 Vue 静态网页。
3. `INIT_KEY` 与 `CONFIG_KEY` 已使用独立的 32 字节加密随机值设置为 Cloudflare Secret。
4. 首次错误使用不兼容的 PowerShell 静态随机数方法后，命令没有正确终止；两把 Secret 随即使用兼容的加密随机数 API 全部轮换，旧值已经失效。
5. 当前 `init_key` 以 Windows 当前用户专属的 DPAPI 密文保存在 Git 忽略的本机临时目录；线上初始化鉴权返回成功，存储模式为 R2。
