## 验收口径

| 项目           |                      数值 |
| -------------- | ------------------------: |
| 已启用用户     |                        50 |
| 合成个人邮件   |                   100,000 |
| 每名用户邮件   |                     2,000 |
| 同时读取用户   |                        10 |
| 每类测量样本   |                       200 |
| 本地数据层阈值 | 第 95 百分位低于 2,000 ms |

工具应用 `migrations/` 中全部 25 个正式迁移，在临时 SQLite 中生成数据，并让 10 个独立线程同时读取不同用户的邮箱。列表查询保留当前服务中的完整性、个人或组织授权、个人状态、会话折叠和发件人关联结构；详情查询保留当前服务的邮箱授权、状态、组织成员与可信发件人结构。读取线程设置 5 秒 SQLite 忙等待，只用于吸收并发连接启动时的瞬时文件锁，不改变 2 秒性能阈值。

## 结果

工具连续执行两次并全部通过：

| 场景             | 第一次第 95 百分位 | 第二次第 95 百分位 | 两次最大单次值 |     阈值 |
| ---------------- | -----------------: | -----------------: | -------------: | -------: |
| 收件箱列表       |          196.31 ms |          258.41 ms |      270.14 ms | 2,000 ms |
| 邮件详情数据查询 |            2.29 ms |            3.22 ms |        5.66 ms | 2,000 ms |

两次运行均完成 50 名用户、100,000 封邮件、200 次列表样本和 200 次详情样本，临时数据库外键检查为零。没有因为首次运行较慢而只记录更好的一次结果。

此前的[中文搜索与 D1 规模验证结果](../验证/中文搜索与D1规模验证结果.md)已经在 100,000 封合成邮件下测得常见中文范围搜索第 95 百分位 48 ms、较少中文词与状态组合 36 ms。两份证据合起来覆盖常用列表、详情数据查询与搜索，但仍不等于完整用户可操作时间。

## 受控简化

1. 合成邮件不写入真实正文和附件对象。临时数据库移除“邮件进入就绪状态前必须具备对象”的插入触发器，以免额外生成 200,000 个不参与本次查询的对象登记；其他正式迁移和外键保持启用。
2. 只生成个人邮箱邮件，不生成组织共享邮件；查询仍保留组织授权连接结构。
3. 本次详情只测 D1 授权和元数据查询，不测 KV/R2 正文对象回读。
4. 本机 SQLite 的线程和文件系统行为不等同于远程 D1。
