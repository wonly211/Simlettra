## 验证目标

1. Outbound Mail Gateway 只接受 Resend 和 SMTP2GO，拒绝 Cloudflare Email Sending。
2. 两家 Provider 均按最终完整 MIME 字节执行 Simlettra 与 Provider 中的较小限制。
3. Resend 使用稳定幂等键安全处理响应丢失；SMTP2GO 结果未知时不自动重发。
4. Resend 使用 Svix 签名验证回调；SMTP2GO 使用专用 HTTPS Basic Auth 凭据。
5. 每名站外收件人独立维护状态；默认 Provider 明确未接受后可以安全切换备用 Provider，结果未知时不能切换。
6. 外部邮箱验证和自动转发复用相同路线及失败边界。

## 真实账号验证

1. 分别发送等于 20,000,000 字节和超过一个字节的最终 MIME，确认 Simlettra 在本地边界拒绝超限邮件。
2. 使用 Resend 测试相同幂等键、响应丢失模拟、重复 Webhook、乱序事件和无效 Svix 签名。
3. 使用 SMTP2GO 测试提交超时、结果未知、重复 Webhook、乱序事件和无效 Basic Auth。
4. 分别验证 Resend 到 SMTP2GO、SMTP2GO 到 Resend 的明确未接受切换。
5. 验证域名路线修改不影响已冻结发送，停用当前配置只能使用冻结路线中的另一家服务。
6. 验证普通发信、外部邮箱验证和自动转发均不产生重复邮件。

## 完成标准

1. 本地数据模型验证通过且外键违规为零。
2. 两家真实测试账号的提交、大小、鉴权、回调、防重、乱序和切换场景全部有可重复证据。
3. 管理页面、API、迁移和恢复路径均不能建立 Cloudflare Email Sending 配置。
4. 失败报告不包含密钥、完整邮件正文或附件内容。
