# 澄笺验证性原型

本目录只保存用于验证架构风险的独立实验，不属于生产工程骨架，也不得被未来生产代码直接依赖。

| 原型 | 用途 | 状态 |
| --- | --- | --- |
| [搜索与规模](搜索与规模/README.md) | 验证中文正文搜索、100,000 封邮件下的 D1 列表与搜索性能 | 本地完成，待远程复核 |
| [邮件解析](邮件解析/README.md) | 验证接近 20 MB 的 MIME 正文、附件、异常结构和运行代价 | 本地有限通过，待远程复核 |
| [对象存储故障恢复](对象存储故障恢复/README.md) | 验证 D1 与 KV/R2 在接收、修复和永久删除中断后的恢复 | 本地完成，待远程复核 |
| [域外发信网关](域外发信网关/README.md) | 历史验证三家候选服务的大小、幂等、结果未知、事件鉴权和状态映射 | 历史原型；当前两家范围需重新验证 |
| [密码与会话](密码与会话/README.md) | 验证密码哈希候选、密码记录、会话摘要、撤销、Cookie、CSRF 和登录限速 | 本地完成，架构已确认，待远程复核 |
| [数据库工具与迁移](数据库工具与迁移/README.md) | 比较原生 D1、Drizzle、Prisma，验证迁移账本、失败回滚和 FTS5 备份恢复 | 本地完成，架构已确认，待远程复核 |
| [数据模型迁移草案](数据模型迁移草案/README.md) | 顺序执行六批迁移草案，验证邮件、发信、删除、配额、备份和迁移约束 | 第六批本地完成，待真实 D1 复核 |

原型统一使用合成数据。可以删除各原型生成的 `.data`、日志和临时结果，再从头执行验证。
