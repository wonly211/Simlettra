# 数据模型迁移草案验证

本原型使用 Node.js 内置 SQLite，从空内存数据库顺序执行当前六批迁移草案。最新脚本验证删除恢复、逻辑与平台双重配额、域名月度发件额度、审计、备份恢复、导出和旧系统迁移；第四批、第五批脚本仍可单独复核此前对象、收信、发信路线和通知转发约束。

本目录不属于生产工程骨架。测试只验证 SQLite 能直接表达的结构和行为，不代替真实 Cloudflare D1、KV、R2、Queue、Worker 或 Drizzle 验证。

## 运行

需要 Node.js 24 或更高版本：

```powershell
node .\第六批数据模型验证.mjs
```

成功时输出自动断言数量、六批累计表数量和外键违规数量。
